# Automated Bulk Inventory Creation with Images
=================================================

This guide shows how to automate creation of 10 inventory items with images in Postman.

## Approach 1: Pre-upload Images (Recommended)
===========================================

### Step 1: Prepare Test Images
---------------------------
1. Create 10 test images with these names:
   - test-product-1.jpg
   - test-product-2.jpg
   - ...
   - test-product-10.jpg

2. Place them in a known folder on your computer

### Step 2: Upload All Images First
-------------------------------

### Collection Setup:
1. Create collection: "Bulk Inventory Creation"
2. Add requests in this order:
   - Login
   - Upload Image 1
   - Upload Image 2
   - ...
   - Upload Image 10
   - Create Inventory 1
   - Create Inventory 2
   - ...
   - Create Inventory 10

### Image Upload Requests (Create 10 of these):
==============================================

### Request 2: Upload Image 1
- **Method**: POST
- **URL**: {{base_url}}/inventory/upload-image
- **Headers**: Authorization: Bearer {{access_token}}
- **Body**: form-data
  - Key: `file`
  - Type: File
  - Value: test-product-1.jpg

### Tests Tab:
```javascript
pm.test("Image 1 uploaded successfully", function () {
    pm.response.to.have.status(200);
    const jsonData = pm.response.json();
    pm.environment.set("image_url_1", jsonData.imageUrl);
    console.log("✅ Image 1 URL:", jsonData.imageUrl);
});
```

### Request 3: Upload Image 2
- **Method**: POST
- **URL**: {{base_url}}/inventory/upload-image
- **Headers**: Authorization: Bearer {{access_token}}
- **Body**: form-data
  - Key: `file`
  - Type: File
  - Value: test-product-2.jpg

### Tests Tab:
```javascript
pm.test("Image 2 uploaded successfully", function () {
    pm.response.to.have.status(200);
    const jsonData = pm.response.json();
    pm.environment.set("image_url_2", jsonData.imageUrl);
    console.log("✅ Image 2 URL:", jsonData.imageUrl);
});
```

*Repeat for images 3-10*

## Approach 3: Automated Image Upload with Postman Scripts (Advanced)
=====================================================================

### Pre-request Script for Dynamic Image Selection:
```javascript
// Select image based on request iteration
const requestNumber = pm.info.iteration || 1;
const imageNumber = (requestNumber - 1) % 10 + 1; // Cycle through 1-10

// Set image file path (this would need to be configured in Postman settings)
pm.environment.set("current_image_file", `test-product-${imageNumber}.jpg`);
pm.environment.set("current_image_url", `/images/test-product-${imageNumber}.jpg`);
```

### Collection Runner Setup:
1. Set iterations to 10
2. Use the pre-request script to cycle through images
3. Each iteration uses a different image

## Collection Structure
===================

1. **Login Request** - Get authentication token
2. **Upload Image 1** - Upload first test image
3. **Upload Image 2** - Upload second test image
4. ...
5. **Upload Image 10** - Upload tenth test image
6. **Create Inventory 1** - Create first product with image 1
7. **Create Inventory 2** - Create second product with image 2
8. ...
9. **Create Inventory 10** - Create tenth product with image 10

## Running the Automation
======================

1. **Prepare Images**: Have 10 test images ready
2. **Setup Environment**: Configure all environment variables
3. **Create Collection**: Add all 21 requests (login + 10 uploads + 10 creates)
4. **Run Collection**: Use Collection Runner with:
   - Iterations: 1
   - Delay: 500ms between requests
5. **Verify Results**: Check all items created successfully

## Summary
==========

This approach allows you to:
1. ✅ Upload 10 images automatically
2. ✅ Create 10 inventory items with variations
3. ✅ Assign specific images to each product
4. ✅ Track all created items with environment variables
5. ✅ Run entire workflow with one click

The key is to upload images first, store their URLs in environment variables, then reference those URLs when creating inventory items.
